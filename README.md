# Calorie Counter App

This is a simple calorie tracking web app built using HTML, Tailwind CSS, and JavaScript. It allows users to add food items with their calorie values, view a running total, and manage their daily intake.

The project demonstrates basic frontend development skills such as DOM manipulation, event handling, and data persistence using localStorage.
---

## Features

- Add food items with calorie values
- Display a dynamic list of foods
- Remove individual items
- Edit existing entries
- View total calories consumed
- Reset daily log
- Persistent data using localStorage

---

## Built With

- HTML5 – Page structure
- Tailwind CSS – Styling and responsive design
- JavaScript – Application logic

---

## How It Works

1. User enters a food name and calorie value.
2. Data is stored in an array and saved to localStorage.
3. The UI updates instantly using DOM manipulation.
4. Total calories are recalculated every time an item is added, edited, or removed.
5. Data remains saved even after refreshing the page.
